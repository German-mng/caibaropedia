# Капибаропедия

Интерактивный веб-атлас и энциклопедия о капибарах (*Hydrochoerus hydrochaeris*). Включает иллюстрированные очерки с полноэкранным режимом чтения, интерактивную карту биомов Южной Америки, этологический квиз и панель управления контентом (CMS).

## Возможности

- Каталог публикаций с живым поиском, фильтрацией по категориям и сортировкой.
- Читальный зал очерка: прогресс чтения, переключение размера шрифта, отметки «Нравится», закладки и комментарии.
- Панель администратора: создание, редактирование и удаление статей, модерация комментариев и статистика просмотров.
- Интерактивная карта ареалов: визуализация биомов обитания капибар на базе Leaflet (Пантанал, Льянос, Амазония, Ла-Плата).
- Этологический квиз: тест на знание повадок капибар с интерактивным выбором ответов.
- Темы оформления: поддержка светлой и тёмной темы с сохранением состояния.
- Обработка ошибок и отказоустойчивость: изоляция сбоев через ErrorBoundary и страница 404.

## Стек технологий

Клиентская часть:
- React 19 (`React.lazy`, `Suspense`)
- React Router 7
- Vite 6
- Tailwind CSS 4
- Framer Motion
- Leaflet
- DOMPurify
- Lucide React

Серверная часть:
- Node.js
- Express
- CORS
- Хранилище данных в формате JSON (`server/data.json`)

## Архитектура

### Маршрутизация и разделение кода
Маршруты приложения настроены через `react-router-dom`. Страницы загружаются асинхронно через динамический импорт (`React.lazy`), что сокращает размер первичного бандла при первой загрузке приложения.

| Маршрут | Назначение |
| :--- | :--- |
| `/` | Главная страница с дашбордом разделов, фактами и фотоархивом |
| `/articles` | Каталог монографий и статей с фильтрами |
| `/articles/:id` | Полноэкранный читальный зал очерка с комментариями |
| `/map` | Интерактивная карта биомов Южной Америки |
| `/quiz` | Интерактивный этологический тест |
| `/admin` | Панель управления контентом (CMS) |
| `*` | Страница 404 с переходом в каталог и глобальный поиск |

### Безопасность
Пользовательский HTML в статьях проходит обязательную очистку библиотекой `DOMPurify` перед выводом на страницу. Это исключает внедрение вредоносных тегов `<script>`, опасных обработчиков событий и XSS-атак.

### Хранение данных
Приложение поддерживает гибридную схему работы:
1. Автономный режим: чтение и запись производятся через `localStorage` браузера без необходимости запускать сервер.
2. Клиент-серверный режим: при запуске Node.js сервера приложение автоматически синхронизирует статьи и комментарии с файлом `server/data.json`.

## Установка и запуск

### Требования
- Node.js версии 18 или новее
- npm

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки

#### Автономный режим (без бэкенда)
```bash
npm run dev
```
Интерфейс доступен по адресу `http://localhost:5173`. Данные сохраняются локально в `localStorage`.

#### С запуском сервера
1. В первом терминале запустите REST API сервер:
```bash
npm run server
```
Сервер запустится на `http://localhost:3001` и синхронизирует базу данных `server/data.json`.

2. Во втором терминале запустите фронтенд:
```bash
npm run dev
```

### Сборка для публикации
```bash
npm run build
```
Готовые оптимизированные файлы будут скомпилированы в директорию `dist/`.
